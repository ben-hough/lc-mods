# Lethal Company mods

Lethal Company mods by Ben Hough (MrGlim). Each mod lives in its own folder with its own README, LICENSE and build files; loader: BepInEx 5 (Thunderstore).

Each folder's full git history was imported from the mod's former standalone repository (paths rewritten into the folder), so `git log --follow <Folder>/<file>` shows the complete history.

## Building and releasing

Each mod builds from its own folder (see that folder's README). Releases are tagged `<ModFolder>-vX.Y.Z`; see [RELEASING.md](RELEASING.md).

## AI disclosure

These mods were made with the help of generative AI (an AI coding agent directed by the author). Each mod's own README keeps its specific AI disclosure.
