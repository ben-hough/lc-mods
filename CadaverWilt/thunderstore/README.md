# CadaverWilt

When a Cadaver Growth patch is fully sprayed away, its bloom enemies wilt and die. Host recommended.

**Thunderstore:** [MrGlim-CadaverWilt](https://thunderstore.io/c/lethal-company/p/MrGlim/CadaverWilt/)  
**Source:** [lc-cadaver-wilt](https://github.com/ben-hough/lc-cadaver-wilt)  
**Game:** Lethal Company (BepInEx)

> **Networking:** Host should install this mod so gameplay changes sync for the lobby.

## Features

- Watches Cadaver Growth patches on the moon
- When every plant in a patch is cleared, linked cadaver blooms die
- Keeps sprayed areas from leaving lingering bloom threats

## Install

1. Install [BepInEx Pack](https://thunderstore.io/c/lethal-company/p/BepInEx/BepInExPack/) for Lethal Company.
2. Install **MrGlim-CadaverWilt** via Thunderstore / r2modman / Gale, or drop `CadaverWilt.dll` into `BepInEx/plugins/`.

Host should run this so wilt behavior applies for everyone.

## Config (`BepInEx/config/com.benhough.lethal.CadaverWilt.cfg`)

No config file in this build — behavior is always on when the plugin loads.
